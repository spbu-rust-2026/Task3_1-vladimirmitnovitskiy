# Зеркальные числа



В лаборатории кафедры алгебры и теории чисел математико-механического факультета СПбГУ обнаружили необычный прибор: он удваивает каждое число и одновременно разворачивает последовательность задом наперёд, поняв насколько это великое изобретение было принято решение его использовать в науке, но увы программное обеспечение прибора сбилось, вам предстоит помочь кафедре АТЧ запрограммировать прибор.

## Задача

Дан вектор из `n` целых чисел. Получите новый вектор, в котором каждый элемент исходного вектора умножен на два, а порядок элементов обратный.

**Требование:** не реализуйте преобразование вручную через цикл — используйте только итераторы и их методы.

## Интерфейс для тестов

Реализуйте и экспортируйте из `src/lib.rs` функцию с такой сигнатурой:

```rust
pub fn mirror_double(numbers: &[i32]) -> Vec<i32>
```

## Рекомендации

- Перед началом работы самостоятельно создайте Rust-проект в этой папке командой `cargo init --name task3_1_template`.
- Разбейте преобразование на понятные шаги и проверьте результат на пустом векторе, одном элементе и нескольких элементах, попробуйте написать собственные тесты.
- Автоматические тесты находятся в `tests/assignment.rs`; запускайте их командой `cargo test`.
- После реализации запустите `cargo fmt` и `cargo check`.
